      Welcome to Battle Bots! 🤖

      You write a program in assembly language, then watch your robot follow it in the arena. Once the match starts, your code is in charge!

      New here? The missions teach one idea at a time, with hints if you get stuck.

      Tip: point at any instruction in the code to see what it does.

      Keyboard shortcuts

      SpaceStart or pause the match
      .Step: run one tick
      RReset the arena
      Ctrl + EnterApply your code
      Ctrl + SSave your code as a .asm file
      Ctrl + /Comment the selected lines out, or back in
      Ctrl + ZUndo
      Tab / Shift + TabIndent / un-indent (works on several selected lines)
      Esc then TabLeave the editor (move to the next button)
      ↑ ↓ Enter EscChoose, use or close a code suggestion
      ?Show this list

      Space, . and R work when you're not typing in the editor. On a Mac, use ⌘ instead of Ctrl.
